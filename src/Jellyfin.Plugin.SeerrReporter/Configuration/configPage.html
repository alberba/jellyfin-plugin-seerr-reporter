Seerr Reporter

Permite a tus usuarios reportar problemas de audio, vídeo o subtítulos desde Jellyfin, creando incidencias en Seerr / Overseerr.

URL base, sin /api. Ej: http://seerr:5055 si ambos contenedores comparten red Docker.
Seerr → Ajustes → General → API Key. Se guarda en el servidor y nunca se envía al navegador.

Tipos de incidencia disponibles

Modifica index.html de jellyfin-web. Requiere que el directorio web sea escribible y recargar la página (Ctrl+F5) tras guardar.
